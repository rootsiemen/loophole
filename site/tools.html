HIGHXSS001–004

Command Injection

Code Injection (eval)

CRITICALEVAL001–002
📡

Server-Side Request Forgery

Your server tricked into calling internal addresses it should never reveal or reach.

HIGHSSRF001
🧬

Prototype PollutionNEW

HIGHPROTO001
📄

XML External Entity (XXE)NEW

Uploaded XML files that make your server hand over its own private files.

HIGHXXE001
🌀

Regex Denial of ServiceNEW
